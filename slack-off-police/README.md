# slack-off-police (サボり警察)

Claude Codeにデバイスの操作権を渡して、勉強・作業のサボりを検知したら
問答無用でプロセスを強制終了させる、Windows専用のネタ実装です。

## できること

1. Claude Codeがチャットで「監視対象ディレクトリ」「作業テーマ」「進捗の判定方法」
   「判定間隔」「落としていいアプリ/サイト」をヒアリングする（初回のみ）
2. 設定を対象ディレクトリに保存し、以降は同じディレクトリなら再ヒアリング無しで起動
3. 一定間隔で `git diff` / ファイル更新日時から進捗の有無を判定
4. 進捗が無く、かつサボり対象のウィンドウが開いていたときだけ `claude -p` を呼び、
   作業テーマと照らして本当にサボりかを判定させる
5. サボり判定なら煽り文をポップアップ表示＋音声再生。1回目は警告、
   2回連続でサボっていたら**確認なしで**該当プロセスを強制終了

```
進捗あり?  ── はい ─→ 見逃す（claude を呼ばない）
   │ いいえ
対象ウィンドウあり? ── いいえ ─→ 見逃す（claude を呼ばない）
   │ はい
claude -p でサボり判定
   ├ 呼び出し失敗 ─→ 見逃す（フェイルセーフ）
   ├ サボりでない ─→ 見逃す（例: 作業テーマに関係する技術解説動画）
   └ サボり ─→ 1回目: 警告 / 2回連続: 強制終了
```

作業テーマに関係する内容（技術解説動画や公式ドキュメント）を見ている場合は
サボり判定にならない。また空行を1行足して保存する程度の変更は進捗と認められず、
その差分ごと判定器に回される。

## 動作環境

- Windows
- Python 3.9+
- `pip install psutil pywin32 pyyaml`
- `claude` CLI（サボり判定に使用。無い場合は `--no-llm` で従来のキーワード判定のみになる）

サボり判定は Claude Code のサブスク枠で動く。**Anthropic API の課金は発生しない。**
1回の判定に10〜20秒、発動するのは「進捗ゼロかつ対象ウィンドウあり」のときだけ。

## セットアップ

Claude Code にこのスキル(`SKILL.md`)を読ませ、監視したいディレクトリで
「勉強サボったら止めて」のように話しかけてください。ヒアリング〜起動までを
Claude Codeが対話的に行います。

手動で使う場合:

```bash
# 初回設定
python scripts/setup.py --dir "C:/path/to/project" --targets "YouTube,Steam" --theme "Rustで自作CLIツールを書く"

# 監視開始（フォアグラウンドで確認したい場合）
python scripts/monitor.py --dir "C:/path/to/project" --audio "assets/your_audio.mp3"
```

常駐させる場合はタスクスケジューラに登録する（詳細は `SKILL.md`）。

## 注意事項

- **2回連続でサボり判定されると、確認なしでプロセスをkillします。**
  保存前のファイルが消える可能性があります。自己責任で。
- ウィンドウタイトルは任意のWebページが自由に書き換えられる文字列なので、
  判定器には全ツールを無効化した状態で渡し、kill対象の選定はローカル判定に固定しています。
- マッチはウィンドウタイトル／プロセス名で行いますが、killは**プロセス単位**です。
  対象タブを開いていたブラウザのプロセスごと落ちるため、他のウィンドウ・タブも巻き込まれます。
- `explorer.exe` などのシステムプロセスと、監視スクリプト自身・その親プロセスは
  キーワードに関わらずkill対象から除外されます。
- 音声ファイルは同梱していません。`assets/README.md` を参照してください。
  実在の配信者・VTuberの音声を無断でリポジトリに含めるのはやめましょう。
- 記事・ネタ用の実装であり、長時間の実運用は想定していません。
