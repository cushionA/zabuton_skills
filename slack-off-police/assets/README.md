# 音声ファイルについて

このリポジトリには音声ファイルを同梱していません。
サボり検知時に鳴らす罵倒ボイスは、著作権的に問題のない音声を各自で用意してください。

- 自分の声で録音したもの
- 利用規約上、再配布・二次利用が明示的に許可されている音声合成キャラ（VOICEVOXなど）
- 実在の配信者・VTuberの切り抜き音声は、本人・事務所の著作物です。
  ローカルで個人的に使うだけであっても、リポジトリに含めて公開するのは避けてください。

用意したファイルをこのディレクトリ（`assets/`）に置き、
`monitor.py` 実行時に `--audio "assets/あなたのファイル名.mp3"` のように指定してください。
